# DDF Sensitivity Test

This folder contains the Directional Distance Function (DDF) 
implementations used to validate the main CCR efficiency results.

Following Färe & Grosskopf (2000) and Ruggiero (1998), terrain-related 
variables were treated as non-discretionary (gx = 0) in three 
configurations per scenario.

Results confirmed that the same roads are classified as efficient/
inefficient under both CCR and DDF across all four functional scenarios.

Reference: Färe, R., & Grosskopf, S. (2000). Theory and application 
of directional distance functions. Journal of Productivity Analysis, 
13(2), 93–103.
